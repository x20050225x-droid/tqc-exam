# TQC 考試題庫測驗系統

各科目線上測驗練習系統，支援隨機出題、加權複習、錯題特訓等功能。

## 科目總覽

| 資料夾 | 科目 | 測驗頁面 | 題庫 |
|--------|------|----------|------|
| `erp/` | 企業資源規劃 (ERP) | 智慧測驗 + 備考系統 + 知識整理 | 229 題 |
| `tqc-database/` | TQC 資料庫設計與應用 | 完整測驗系統 | 4 份題庫（第 1~9 章） |
| `supply-chain/` | SUP-SC 供應鏈管理 | 專項測驗系統 | 題目內嵌 |
| `logistics/` | 國際貨櫃運輸 + 物流資訊平台 | 極速測驗 | 題目內嵌 |
| `ec/` | 跨境電子商務 | *(題庫待建立測驗頁面)* | 題庫已整理 |
| `pm/` | 專案管理 | *(題庫待建立測驗頁面)* | 題庫已整理 |

## 功能特色

- **隨機測驗**：從題庫隨機抽選指定題數進行測驗
- **加權隨機**：常錯題目出現機率較高，兼顧複習與新題
- **錯題特訓**：直接鎖定錯誤權重最高的題目進行特訓
- **進度追蹤**：使用 localStorage 儲存學習進度與錯題權重

## 使用方式

直接用瀏覽器開啟各資料夾中的 `index.html` 即可使用，無需安裝任何套件。

## 資料夾結構

```
tqc-exam/
├── README.md
├── erp/                        # ERP 企業資源規劃
│   ├── index.html              #   智慧測驗系統
│   ├── study.html              #   智慧備考系統
│   ├── knowledge.html          #   知識整理
│   └── questions.js            #   題庫（229 題）
├── tqc-database/               # TQC 資料庫設計與應用
│   ├── index.html              #   完整測驗系統
│   ├── questions_part1.js      #   題庫 Part 1（第 1~3 章）
│   ├── questions_part2.js      #   題庫 Part 2（第 3~4 章）
│   ├── questions_part3.js      #   題庫 Part 3（第 5~6 章）
│   └── questions_part4.js      #   題庫 Part 4（第 7~9 章）
├── supply-chain/               # SUP-SC 供應鏈管理
│   └── index.html              #   專項測驗系統（題目內嵌）
├── logistics/                  # 國際貨櫃運輸 + 物流資訊平台
│   └── index.html              #   極速測驗（題目內嵌）
├── ec/                         # 跨境電子商務
│   └── questions.js            #   題庫（待建立測驗頁面）
└── pm/                         # 專案管理
    └── questions.js            #   題庫（待建立測驗頁面）
```
